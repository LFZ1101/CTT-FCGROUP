# Fase 7 — Integrações (framework)

Conforme Documento Mestre §66: **não criar integração fake**.

## Entregue

- Catálogo `ONVIO` / `DOMINIO` / `ALTERDATA` / `OTHER`
- Model `IntegrationConnection` para registrar intenção
- API `GET /integrations`, `POST /integrations/intent`
- UI `/integracoes` com limitações explícitas

## Não entregue (bloqueado até API/credenciais)

- Sync real de colaboradores/folha com ONVIO, Domínio ou Alterdata

Até lá, use importação CSV de colaboradores.
